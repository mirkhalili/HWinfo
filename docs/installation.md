# نصب
1. PHP 8.2+ و MySQL 8+ نصب کنید.
2. schema.sql را اجرا کنید.
3. متغیرهای DB را تنظیم کنید.
4. `php scripts/create-admin.php admin 'یک-رمز-قوی' 'مدیر سامانه'`
5. وب‌ریشه را روی public تنظیم کنید.
6. HTTPS را فعال کنید.
7. collector را روی کلاینت Windows اجرا و CSV را به کارشناس تحویل دهید.
8. کارشناس از منوی ورود CSV فایل را وارد می‌کند؛ رکوردها pending می‌شوند و سپس تأیید/رد و تخصیص انجام می‌شود.
